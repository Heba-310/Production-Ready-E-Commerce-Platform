# SwiftCart – E-Commerce Platform

A responsive e-commerce web application built with React.js and Bootstrap, offering a seamless shopping experience from product browsing to checkout.

## Live Demo

[View Live Demo](https://subtle-clafoutis-e49ea6.netlify.app)

## Features

* Responsive design for different screen sizes
* Product browsing and shopping cart management
* End-to-end shopping and checkout experience
* Lazy Loading for improved performance
* Product data management using JSON Server

## Technologies

* React.js
* Bootstrap
* JavaScript (ES6+)
* JSON Server
* Lazy Loading

## Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-folder>
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start JSON Server:

   ```bash
   npx json-server --watch src/DataBase.json --port 3001
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```
