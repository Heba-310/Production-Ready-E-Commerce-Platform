## Features

* Responsive design for different screen sizes
* Product browsing and shopping cart management
* Checkout functionality
* Lazy Loading for improved performance
* Product data management using JSON Server

## Technologies

React.js, Bootstrap, JavaScript (ES6+), JSON Server, Lazy Loading

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Heba-310/Production-Ready-E-Commerce-Platform.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Production-Ready-E-Commerce-Platform
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start JSON Server:

   ```bash
   npx json-server --watch src/DataBase.json --port 3001
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```
